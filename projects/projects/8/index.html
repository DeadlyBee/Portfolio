KinderConnect

KinderConnect is a full-stack web application developed as my Projet de Fin d’Année (PFA). The project was fully documented, implemented, and formally presented to an academic jury as part of my degree requirements, where it received a strong evaluation.

Project Description

The platform is designed to manage daily kindergarten operations through a structured, role-based system involving Admins, Teachers, and Parents.

- Admin users manage accounts, assign children to classes, and oversee the system.
- Teachers create schedules, add notes, and evaluate children through grades and feedback.
- Parents securely access their children’s academic information, including schedules, grades, and teacher notes.
The application integrates authentication, relational database management, and dynamic user interfaces to ensure secure access and smooth data flow between roles. Special attention was given to database design, data consistency, and usability, reflecting professional project standards.

"“A strong system is not just built — it is defended, documented, and proven.”"

Learning Outcomes & Purpose
As a PFA project, the objective was to demonstrate mastery of full-stack web development and software engineering fundamentals.

oral presentation and project defense before a jury
