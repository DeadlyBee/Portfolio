ArcadeX

A full-stack e-commerce web application for selling gaming equipment.

Project Overview

ArcadeX is a full-stack e-commerce web application focused on selling electronic gaming products such as monitors, keyboards, mice, and gaming accessories. The project demonstrates how a modern frontend framework can seamlessly interact with a powerful backend through RESTful APIs.

Project Description

This project was developed independently and covers both frontend and backend layers. The frontend was built using Angular to create a responsive, component-based user interface suitable for an online store experience. The backend was developed with Spring Boot, responsible for handling product data, business logic, and CRUD operations through RESTful web services.

The application architecture follows a clear separation of concerns, allowing the frontend and backend to evolve independently. ArcadeX simulates a real-world e-commerce environment, focusing on structured data handling, scalability, and clean API communication.

"ArcadeX allowed me to apply full-stack concepts to a real e-commerce use case, from API design to user-facing interfaces.”"

Learning Outcomes & Purpose
The main goal of ArcadeX was to gain hands-on experience in building a complete e-commerce system using modern web technologies. Through this project, the following skills were developed:

⦿ Designing RESTful APIs for product management
⦿ Implementing CRUD operations in a backend system
⦿ Connecting Angular services to backend endpoints
⦿ Structuring a scalable full-stack application
⦿ Developing an e-commerce-oriented data flow
