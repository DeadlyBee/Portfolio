AR Animal Explorer

An interactive augmented reality (AR) learning experience for kids

Project Overview

AR Animal Explorer is a mobile augmented reality application created for children to transform traditional learning into an engaging, interactive experience. The project is based on a custom-designed animal book containing images and descriptions of different animals.

When the user opens the application and scans an animal image from the book, the app recognizes the image and displays interactive 3d animal modele and buttons directly on the screen. These buttons allow children to explore the animal in multiple ways:
-A Sound button plays the real sound of the animal, helping children associate visuals with audio learning.
-A Video button displays a short educational video showing the animal in its natural environment.

Project Overview

"This project was designed to combine education and technology, making learning more dynamic and enjoyable. Through this application, children can engage visually, audibly, and interactively, improving memory retention and curiosity."

Learning Outcomes & Purpose

This project helped me deeply understand how augmented reality can be used in educational applications. I learned how to:
-Integrate AR image tracking with real-world objects
-Connect physical learning materials with digital interactions
-Work with 3D models in a mobile AR environment
-Design intuitive user interactions suitable for children
