Echrini

A full-stack e-commerce platform for selling gym and fitness equipment.

Project Overview

Echrini is a full-stack e-commerce web application designed for selling gym and fitness equipment online. The project focuses on building a robust backend architecture that supports all essential online store functionalities, including product management, user interactions, and secure data handling. The system follows modern web development practices using RESTful APIs to ensure scalability, maintainability, and smooth communication between the frontend and backend.

Project Description

The core of this project is a Spring Boot backend that exposes RESTful web services to manage products, users, and store operations. It implements complete CRUD functionality, allowing products to be created, updated, retrieved, and deleted efficiently through well-structured API endpoints. The backend is connected to a database to store product data, ensuring data persistence and integrity.

On the frontend side, Angular is used to consume these APIs and display the store content dynamically. This separation between frontend and backend allows the application to be modular, flexible, and easily extendable. Through this project, I gained practical experience in backend development, API design, database integration, and full-stack application structure, while also understanding how real-world online stores are built and managed.
