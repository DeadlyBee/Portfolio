Dodgie2D

2D Unity Game Tutorial for Beginners.

Project Description

Unity Jump & Dodge is a simple 2D game developed as an educational project during a Unity teaching session at the Gaming Freaks university club. The game was designed to introduce beginners to essential Unity concepts through a clear and interactive example.

Project Description

In this game, the player controls a character using the keyboard to move and jump while avoiding a red enemy that automatically moves left and right. The core mechanic relies on collision detection: when the player collides with the red enemy, the game immediately triggers a Game Over state.

Upon losing, a Game Over screen appears with a Restart button, allowing the player to replay the game. This simple loop helped demonstrate how collisions, conditions, and scene control work together inside Unity.
The project was intentionally kept simple so that learners could clearly understand how movement scripts, enemy behavior, collision logic, and UI elements interact within a 2D game environment.

"“A simple collision can teach the foundation of an entire game.”"

Learning Outcomes & Purpose
The main purpose of this project was educational. It allowed me to teach Unity fundamentals in a practical way while strengthening my own understanding of core game development principles.
Through this project, I gained experience in:

⦿ Teaching technical concepts clearly to beginners
⦿ Implementing collision-based lose conditions
⦿ Creating player movement and jump mechanics
⦿ Programming basic enemy AI movement
⦿ Enhancing immersion through spatial interaction
