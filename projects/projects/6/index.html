MarketHub

Angular Market Application with API & Database Integration

Project Overview

MarketHub is a web-based market application developed using Angular for the frontend, with backend data management handled through a local server environment. The project simulates a real online market by combining a structured user interface with dynamic data fetched from a database and tested through APIs.

Project Description

This project was designed to go beyond static frontend development by integrating real data and API communication. The application displays market products dynamically, with data stored and managed through a local server environment using XAMPP.

RESTful endpoints were tested and validated using Postman to ensure proper data flow between the frontend and backend. This allowed the application to retrieve, display, and manage product data in a way that reflects real-world market systems.

The Angular frontend focuses on component-based design, routing, and clean UI organization, while the backend setup emphasizes data consistency and API testing. Together, they form a complete and realistic market application workflow.

“Seeing real data flow from the database to the interface turned this project from a simple UI into a real-world application.”

Learning Outcomes & Purpose
The main goal of this project was to understand how frontend applications interact with backend services and databases. Through this project, I gained practical experience in:

⦿ Connecting Angular applications to backend data sources
⦿ Managing and displaying dynamic data
⦿ Testing REST APIs using Postman
⦿ Using XAMPP for local server and database management
⦿ Structuring market-style web applications

Technologies & Tools Used


Angular TypeScript, HTML, CSS


Backend XAMPP-MySQL


REST API Postman
